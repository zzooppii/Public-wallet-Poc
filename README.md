# MetaMask Clone PoC (Web3 Wallet Extension)

이 디렉토리는 메타마스크와 같은 "브라우저 익스텐션 핫월렛(Hot Wallet)"이 내부적으로 어떻게 동작하는지 뜯어보기 위해 만든 **핵심 기능 증명용(PoC)** 미니 프로젝트입니다.

블록체인 지갑이 웹사이트(DApp)와 어떻게 이야기하는지, 15분 만에 본질을 이해할 수 있습니다.

## 🦊 지갑의 3단 구조 (코드 설명)

1. **`injected.js` (목마 스크립트)**
   - 자기가 메타마스크인 척(`window.ethereum.isMetaMask = true`)하면서, 웹페이지의 자바스크립트 환경에 전역 객체를 몰래 심어둡니다. 유니스왑 같은 DApp이 트랜잭션 요청을 보낼 때 이 객체를 호출합니다.

2. **`content.js` (중계기)**
   - `injected.js` (보안이 없는 일반 웹페이지)와 `background.js` (보안이 철저한 확장 프로그램 내부) 사이에서 우체부 역할을 합니다. DApp이 보낸 메시지를 받아서 백그라운드로 안전하게 전달합니다.

3. **`background.js` (지갑의 두뇌 / 보안 금고)**
   - 브라우저가 실행되는 내내 보이지 않는 곳에서 백그라운드로 돕니다. 실제라면 암호화된 사용자의 프라이빗 키를 여기서 관리하며, 팝업창을 띄워 연결 승인을 받거나, DApp의 송금 요청을 거절/승인합니다. (이 PoC에서는 무조건 승인된 주소를 넘겨주도록 하드코딩 되어 있습니다.)

4. **`popup.html` & `popup.js` (사용자 인터페이스)**
   - 크롬 우측 상단 퍼즐/여우 아이콘을 눌렀을 때 뜨는 UI입니다.

---

## 💻 내 크롬 브라우저에 직접 설치해보기 (1분 컷)

실제로 이 확장 프로그램을 내 크롬에 직접 깔아볼 수 있습니다!

1. 크롬(Chrome) 브라우저를 열고 주소창에 **`chrome://extensions/`** 를 입력하고 들어갑니다.
2. 우측 상단에 있는 **[개발자 모드 (Developer mode)]** 토글 버튼을 켜주세요 (스위치 파란색 🟢).
3. 왼쪽 위에 생긴 **[압축해제된 확장 프로그램을 로드합니다 (Load unpacked)]** 버튼을 클릭합니다.
4. 방금 생성된 **현재 폴더(Metamask-Clone-PoC)** 자체를 선택해서 열기(Open)를 누릅니다.
5. 짠! 크롬 확장 프로그램 목록에 **"MetaMask Clone PoC"**가 등록되었습니다.
6. 우측 상단 퍼즐 모양 아이콘을 눌러, 이 지갑을 고정(Pin 📌) 시켜보세요.
7. 여우 모양 팝업창을 클릭하면 아까作った `popup.html` UI가 귀엽게 뜨는 것을 볼 수 있습니다.

## 🧪 DApp 속이기 놀이 (테스트)

이 지갑이 얼마나 웃기게(?) 작동하는지 테스트해 볼 수 있습니다.

1. 크롬을 열고 **아무 웹사이트(예: https://etherscan.io)나 들어갑니다.**
2. 무조건 마우스 우클릭 -> **[검사 (Inspect)]** 를 눌러 '개발자 도구(DevTools)'를 엽니다.
3. **[Console(콘솔)]** 탭에 들어갑니다.
4. 콘솔 창에 아래 코드를 복사 붙여넣기 해보세요. (유니스왑이 뒷단에서 하는 방식과 완전히 동일합니다)
   ```javascript
   window.ethereum.request({ method: 'eth_requestAccounts' }).then(console.log);
   ```
5. 결과값으로 `['0xYourCustomWalletAddress1234...']` 이라는 우리의 조작된 주소가 튀어나옵니다! 즉, 유니스왑이 "로그인 됐네?" 하고 속아 넘어가는 원리입니다.
